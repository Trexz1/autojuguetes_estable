# Uso de agentes comerciales para vender automatizaciones

Estos agentes no modifican el código. Se usan para vender sistemas como JugueteríaBot, automatizaciones WhatsApp, paneles FastAPI/React, integraciones con SQL Server, bots de soporte y sistemas de inventario.

## Sales Outreach

Sirve para crear mensajes de prospección: WhatsApp, correo, DM o llamada inicial.

Uso práctico:
- Identificar tipo de negocio: juguetería, papelería, boutique, restaurante, gimnasio, consultorio.
- Crear mensaje corto centrado en dolor real: respuestas lentas, pérdida de pedidos, desorden de inventario o falta de seguimiento.
- Proponer una demo concreta, no vender humo.

Ejemplo de enfoque:

```text
Detectamos negocios que pierden pedidos por responder tarde en WhatsApp. Se ofrece automatización con catálogo, pedidos y panel administrativo.
```

## Proposal Strategist

Sirve para convertir una oportunidad en una propuesta formal.

Uso práctico:
- Definir alcance exacto.
- Separar entregables incluidos y no incluidos.
- Poner precio por fases.
- Incluir tiempos, garantías, mantenimiento y condiciones de pago.
- Evitar proyectos abiertos sin límite.

## Sales Engineer

Une la venta con la solución técnica.

Uso práctico:
- Explicar cómo se conecta WhatsApp Cloud API, FastAPI, SQL Server y panel web.
- Traducir necesidades del cliente a módulos técnicos.
- Detectar limitaciones reales: cuentas Meta, tokens, dominio, ngrok, servidor, base de datos, seguridad y costos.

## Deal Strategist

Sirve para decidir si conviene aceptar un proyecto y cómo cobrarlo.

Uso práctico:
- Evaluar riesgo técnico y riesgo de cliente.
- Definir pago inicial, pagos por avance y entrega final.
- Separar desarrollo, instalación, soporte y mejoras.
- Evitar aceptar cambios ilimitados por el mismo precio.

## Content Creator

Sirve para publicar contenido que atraiga clientes.

Uso práctico:
- Videos cortos mostrando antes/después.
- Casos: “cómo automatizar pedidos por WhatsApp”.
- Publicaciones con problemas reales de negocios locales.
- Demostraciones del panel y del bot.

## Analytics Reporter

Sirve para demostrar valor después de instalar.

Uso práctico:
- Reportar consultas recibidas.
- Productos más preguntados.
- Pedidos generados.
- Clientes nuevos.
- Horarios con más actividad.
- Tasa de consultas sin respuesta o productos no encontrados.

## Flujo comercial recomendado

1. Sales Outreach consigue contacto.
2. Sales Engineer hace diagnóstico técnico.
3. Proposal Strategist arma propuesta formal.
4. Deal Strategist define precio, pagos y límites.
5. Content Creator genera material para captar más clientes.
6. Analytics Reporter demuestra resultados para renovación, soporte o upsell.
